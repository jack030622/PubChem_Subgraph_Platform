# Structural clustering experiments

Owner tasks: T005 for the label-free baseline and T011 for assay-conditioned neighborhood analysis. A global cluster is built from frozen structural features only. Compare Morgan and BRICS at matched coverage and cluster/search budgets. Measure stability, held-out assay outcome consistency, active chemotype/scaffold diversity, and retrieval recall after any cluster-based candidate restriction. Do not select global clusters using held-out labels or claim biological meaning from visual separation alone.
